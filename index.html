Madura Dictionary API

English ↔ Sinhala translation Vercel KV cache

Base URL

API https://my-dictionary-api.vercel.app

Endpoint

GET /api/translate?word={word}

Query Parameters

Parameter Type Description
word required string English or Sinhala word to look up. (e.g. dance or නැටුම)

Example Requests

cURL

curl "https://my-dictionary-api.vercel.app/api/translate?word=dance"

Browser / Fetch

fetch("https://my-dictionary-api.vercel.app/api/translate?word=නැටුම") .then(res => res.json()) .then(data => console.log(data));

Sinhala query (URL‑encoded)

https://my-dictionary-api.vercel.app/api/translate?word=%E0%B6%B1%E0%B7%90%E0%B6%A7%E0%B7%94%E0%B6%B8

Example Response

{ "source": "cache", "word": "dance", "translations": [ { "english": "dance", "sinhala": "නැටුම", "type": "n." }, { "english": "dance", "sinhala": "නටනවා", "type": "v." } ] }

source indicates whether the result was served from cache ("cache") or freshly scraped ("scrape").

Error Responses

If something goes wrong, the API returns a 500 or 400 status with a JSON error object:

{ "error": "Failed to fetch translation", "details": "No translations found for \"xyz\"" }
  • 400 – Missing word parameter.
  • 404 – (not used, but could be if route not found).
  • 500 – Scraping failed, network issues, or no translations.

Caching & Performance

  • Vercel KV stores each word’s translation for 7 days.
  • First request for a word fetches from Madura Online (scrape). Subsequent requests are served from cache – lightning fast.
  • No explicit rate limits, but please use responsibly. The cache reduces load on the source website.
